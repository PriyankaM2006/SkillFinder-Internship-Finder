# SkillFinder – Internship Finder

A frontend-based web application designed to help students explore internship opportunities based on their skills and interests.

## Features

### Student Side
- Explore internship opportunities
- Browse available internships
- View skills and career-related information
- User registration and login
- Manage user profile

### Admin Side
- Admin login page

## Tech Stack
- Frontend: HTML, CSS, JavaScript

## Getting Started

### Prerequisites
- Python (if using a Flask/Jinja setup)

- Web Browser

### Run the Project
1. Clone the repository.
2. Open the project folder in Visual Studio Code.
3. Run the project using the appropriate local development setup.
